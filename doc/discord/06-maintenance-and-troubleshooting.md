# 06. Maintenance & Troubleshooting 🔧

This guide provides operational runbooks, troubleshooting steps, and health check procedures for maintaining the SaveDino Discord integration.

---

## 🔄 Registering & Updating Slash Commands

### Option A: Using the Admin Web API (Recommended)

You can register or refresh the `/link` slash command by making an authenticated POST request as an admin:

```bash
# Register to your specific Guild (Updates INSTANTLY in Discord)
curl -X POST https://savedino.sedssl.org/api/admin/discord/register-commands \
  -H "Content-Type: application/json" \
  -H "Cookie: better-auth.session_token=YOUR_ADMIN_SESSION_COOKIE" \
  -d '{"guildId": "134567890123456789"}'
```

_(Note: Global commands take up to 1 hour to propagate across Discord, whereas passing `guildId` registers the command instantly for your server)._

## 🛠️ Common Troubleshooting Scenarios

### 1. Webhook Validation Failed: "Invalid request signature" (401)

- **Cause**: The `DISCORD_PUBLIC_KEY` in `.env` does not match the **Public Key** in the Discord Developer Portal, or raw body parsing was modified.
- **Fix**:
  1. Open Discord Developer Portal $\rightarrow$ General Information.
  2. Copy the 64-character **Public Key** hex string.
  3. Update `DISCORD_PUBLIC_KEY` in `.env` and restart the server.
  4. Ensure `req.text()` is read without modification in `app/api/discord/interactions/route.ts`.

---

### 2. Role Assignment Failed: "403 Forbidden / Missing Permissions"

- **Cause**: The `SaveDino Bot` role is lower in the Discord Role Hierarchy than the `@Citizen Scientist` or campaign role, or the bot is missing the `Manage Roles` permission.
- **Fix**:
  1. Go to Discord **Server Settings** $\rightarrow$ **Roles**.
  2. Drag the **SaveDino Bot** role above `@Citizen Scientist` and `@Squad Leader`.
  3. Ensure the bot has `Manage Roles` enabled.

---

### 3. Thread Creation Failed: "50001 Missing Access"

- **Cause**: The bot does not have permissions to view or create threads in `#🛡️・squad-headquarters`.
- **Fix**:
  1. Right-click `#🛡️・squad-headquarters` $\rightarrow$ **Edit Channel** $\rightarrow$ **Permissions**.
  2. Add `SaveDino Bot` and grant:
     - `Create Public Threads`
     - `Create Private Threads`
     - `Send Messages in Threads`
     - `Manage Threads`

---

### 4. "Link token expired" or "Invalid token"

- **Cause**: Tokens generated by `/link` expire after 15 minutes for security.
- **Fix**: The user simply needs to run `/link` again in Discord to generate a fresh 15-minute token.

## 🚀 Pre-Campaign Launch Health Checklist

Run through this 5-minute checklist before launching an asteroid search campaign:

- [ ] **Interactions Endpoint**: Discord Developer Portal shows green checkmark for `https://savedino.sedssl.org/api/discord/interactions`.
- [ ] **Slash Command**: Typing `/link` in Discord presents the SaveDino command and responds with the private button.
- [ ] **Link Verification**: Clicking the button redirects to `/link-discord` and awards `@Citizen Scientist`.
- [ ] **Squad Automation**: Creating a test squad on SaveDino generates a thread in `#🛡️・squad-headquarters`.
- [ ] **Support Desk**: Clicking "Open Support Ticket" in `#🎫・support-desk` creates a private ticket channel and logs to `#🔒・bot-logs`.
- [ ] **AutoMod**: Dyno AutoMod filters are active with banned words and anti-invite protection.
